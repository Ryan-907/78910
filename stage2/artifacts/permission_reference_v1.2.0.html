This page is reference only. Author the decisions in permission_template_v1.2.0.csv: one row per information type, one column per role, each cell permit or deny. Then run python -m stage2.validate_permissions.

The question each cell asks is: may this role receive this information type about the document’s subject? The check runs only after role, context, and assignment have already passed, so a permit here does not grant access on its own — it declines to withdraw it.
Counts below are per information type and never per (role, type). A per-cell figure would be the outcome of that cell’s decision rather than input to it. Nothing here is prefilled or recommended; the provenance of these sets is the point.

A clinician credential identifier — state medical license, NPI, or DEA registration number. OWNERSHIP BOUNDARY (v1.2.0): an NPI is syntactically identical whether individual or organisational, so ownership follows the entity the credential is asserted of.
